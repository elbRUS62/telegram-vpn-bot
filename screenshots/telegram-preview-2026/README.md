# Превью SkrepNet для Telegram

Демонстрационные материалы для предпросмотра Mini App в BotFather.

## Файлы

- `01-main.png` — главный экран.
- `02-subscription.png` — подписка и срок.
- `03-subscription-qr.png` — QR-код и кнопки подключения.
- `04-donate.png` — поддержка проекта.
- `05-support.png` — помощь и обращения.
- `00-cover.png` — обложка для видео.
- `skrepnet-miniapp-preview.mp4` — короткое видео-обзор.
- `skrepnet-miniapp-preview.zip` — архив для загрузки.

## Куда загрузить

1. Открыть BotFather.
2. Выбрать `SkrepNet`.
3. Открыть настройки Mini App.
4. Нажать «Предпросмотр» / «Добавить предпросмотр».
5. Загрузить изображения `01`–`05` и видео.
6. Сохранить.

В превью используются только демонстрационные данные. Реальные пользователи и их QR-коды не показаны.
